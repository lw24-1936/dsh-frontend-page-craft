# 前端页面工坊

**一个技能，把「做页面」变成四步可验收的工程**：需求分析 → 设计 → 实现 → 验收。

## 能做

- 新做或重做前端页面：后台管理、仪表盘、营销落地页、移动 H5、数据大屏、文档站、AI 对话产品。
- 选型：框架、UI 组件库、图表库、动画库、富文本编辑器、3D 引擎——按生态与维护状态筛选，不选停更库。
- 建立设计系统：4 个视觉方向、可直接复制的 CSS 令牌、字号/间距/圆角/阴影/动效规范。
- 质量门禁：四态齐全、键盘可达、对比度 ≥ 4.5:1、三档响应式、首屏 JS ≤ 200KB，以及 15 条反 AI 味自检。

## 怎么工作

1. **判页面类型**：先归入 7 类范式之一，决定骨架、密度与必读资源。
2. **Brief**：用户、场景、真实内容、约束、可测验收标准；只在阻塞时问不超过 3 个问题。
3. **Design**：选一个视觉方向 → 定令牌 → 布局骨架 → 组件映射表（必须查目录）。
4. **实现**：骨架 → 静态内容 → 四态 → 交互 → 响应式 → 动效 → 清理。
5. **验收**：P0 全过才交付；不能开浏览器时明确写「视觉未验证」。

## 内置目录

移动端 10 个、PC 端 17 个、可视化与大屏 15 个、动画 8 个、编辑器 3 个、3D 7 个、其他 8 个，共 68 个条目，逐个标注生态、维护状态（可用 / 旧生态 / 停更 / 商业 / 社区 / 未知）、适用与不适用场景、安装包名。

## 限制

- 只做选型与流程，不替代官方文档；组件 API 以官网为准。
- 不自动装依赖、不改用户项目结构。
- 生命周期结论核对于 2026-11-15，之后可能变化，采用前请复核。
