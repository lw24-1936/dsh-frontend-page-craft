# 验收清单

用法：P0 全过才算完成；P1 未过要写进 `VERIFY.md` 的遗留项。每项都要有**验证方式**，不能只勾「感觉没问题」。

## P0（必须全过）

### 需求与内容
- [ ] 首屏 3 秒能回答「这是什么、给谁、下一步做什么」——用截图问一个没看过需求的人
- [ ] 文案里没有 Lorem / foo / 「示例文本」/ 12345 这类占位——全文搜索
- [ ] 每个区块都有明确信息目的；删掉任意区块不影响主任务 → 说明该区块可删
- [ ] 主 CTA 一屏只有一个，且按钮文案是动词

### 四态
- [ ] loading：有骨架或局部 spinner，不白屏、不整页闪——断网/慢网模拟
- [ ] empty：有说明 + 下一步动作——构造 0 条数据
- [ ] error：有原因 + 重试，不暴露堆栈——阻断接口返回 500
- [ ] 边界：超长文本（200 字）、0/1/1000 条、无权限——逐一构造

### 可访问性
- [ ] 正文对比度 ≥ 4.5:1，大字 ≥ 3:1——取色器抽检 3 处（正文/次要文字/按钮）
- [ ] 纯键盘可完成主流程，焦点环可见——只用 Tab/Enter/Esc 走一遍
- [ ] 所有图标按钮有可读名称（`aria-label`）——读 DOM
- [ ] 不只用颜色表达状态（错误/成功有图标或文案）
- [ ] 触控目标 ≥ 44×44px——移动端量测

### 响应式
- [ ] 390 / 768 / 1440 三档无横向滚动、无遮挡——三档截图
- [ ] 移动端主操作在首屏且可单手触达
- [ ] 图片/图表不溢出容器，有预留高度（CLS ≤ 0.1）

### 技术
- [ ] 控制台无报错/无未处理 Promise 拒绝
- [ ] 首屏 JS（gzip）≤ 200KB（图表/编辑器/3D 已懒加载）
- [ ] 无 `eval`、无未消毒 `v-html`/`dangerouslySetInnerHTML`
- [ ] 外链 `rel="noopener noreferrer"`
- [ ] 无硬编码密钥、无敏感信息进日志

### 反 AI 味（对照技能正文 15 条）
- [ ] 不是紫渐变三卡片；不是 emoji 图标；不是全居中卡片汤
- [ ] 标题/正文层级跳档 ≥ 1.25×；同类元素一套圆角/阴影
- [ ] 动效 ≤ 2 处入场，且尊重 `prefers-reduced-motion`

## P1（记录为遗留，不阻塞）

- [ ] 深浅主题切换无白闪、图表配色独立
- [ ] 骨架屏与实际布局等高，切换不跳动
- [ ] 表单错误就近显示 + 自动滚动到首个错误
- [ ] 表格数字右对齐、表头吸顶、操作列固定
- [ ] 长列表（>200）滚动流畅
- [ ] 图片有 `alt`；装饰图 `aria-hidden`
- [ ] 404 / 无权限 / 维护中有独立页面
- [ ] SEO：title/description/OG 图（营销站必做）
- [ ] 打印/导出样式（如需）
- [ ] 国际化文案已抽取（如需）
- [ ] 埋点/错误上报已接入（如需）

## 视觉验收（有浏览器时）

1. 三档视口截图：390×844、768×1024、1440×900。
2. 检查：溢出、断行、对齐、遮挡、焦点环、空态。
3. 抽检对比度 3 处（正文/次要/按钮文字）。
4. 连续操作主流程 2 遍，确认无状态残留。
5. 深色模式（如有）再截一轮。

**没有浏览器控制时**：只报告静态检查结论，写「视觉未验证」，不得声称已验收通过。
