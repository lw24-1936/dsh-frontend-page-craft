# 页面范式：结构骨架与常见坑

每个范式包含：线框、必备区块、组件映射、陷阱、验收要点。**先按线框搭骨架，再填内容，最后调样式**——反过来必然返工。

---

## 后台管理

```
┌──────┬──────────────────────────────────────────────┐
│ 侧栏 │ 顶栏：面包屑 · 搜索 · 通知 · 用户             │
│ 240  ├──────────────────────────────────────────────┤
│ 可折叠│ 页头：标题 + 主操作（新建/导出）              │
│      │ 筛选区：条件 + 重置（可折叠）                 │
│      │ 表格：列固定/排序/选择/分页                   │
│      │ 抽屉/弹窗：详情与编辑                         │
└──────┴──────────────────────────────────────────────┘
```

- 必备：侧栏导航（含当前项高亮）、页头主操作（一屏一个主按钮）、筛选、表格（含空/错/慢）、分页、行操作、危险操作二次确认、权限隐藏而非禁用。
- 组件映射：Element Plus（`el-menu` `el-table` `el-form` `el-pagination` `el-drawer`）/ Ant Design Vue（`a-layout` `a-table` `a-drawer`）。
- 陷阱：筛选条件不进 URL（无法分享/刷新丢失）；表格不吸顶表头；危险按钮用主色；空状态没有「新建」入口；加载时整页骨架而不是表格区域骨架。
- 验收：筛选→刷新→URL 保持；1000 行不卡（虚拟滚动或分页）；键盘可完成「搜索→选中→编辑→保存」。

## 仪表盘

```
┌──────────────────────────────────────────────┐
│ 标题 + 时间范围 + 刷新                        │
├────────┬────────┬────────┬───────────────────┤
│ 指标卡 │ 指标卡 │ 指标卡 │ 主趋势图（2/3 宽）│
├────────┴────────┴────────┴───────────────────┤
│ 分布图（1/3）        │ 明细表/排行榜（2/3）  │
└──────────────────────────────────────────────┘
```

- 必备：时间范围切换、指标卡（数值 + 同比 + 口径说明）、主图（趋势）、辅助图（分布/构成）、下钻入口、数据时间戳。
- 组件映射：ECharts（line/bar/pie，按需引入）+ 卡片容器；Vue Data UI 适合小型指标组件。
- 陷阱：图表没有单位与图例；颜色随意；指标卡数字不右对齐/不等宽；刷新时整页 loading 闪烁；把「实时」写成静态数据。
- 验收：数字与图表口径一致；无数据时图区显示空状态；深色模式图表配色独立；1440 与 1024 两档不错位。

## 落地页

```
┌──────────────────────────────────────────────┐
│ 顶栏（logo · 导航 3-5 项 · 主 CTA）           │
│ 首屏：H1 主张 + 一句副标题 + 主/次 CTA + 证据 │
├──────────────────────────────────────────────┤
│ 社会证明（客户 logo / 数据 / 评价）            │
│ 核心能力（3 块，每块：标题 + 说明 + 真实截图） │
│ 使用流程（3-4 步）                            │
│ 对比 / 报价 / FAQ                             │
│ 结尾 CTA + 页脚                               │
└──────────────────────────────────────────────┘
```

- 必备：一句人话主张（谁、解决什么）、主 CTA（一屏一个）、真实证据（截图/数据/客户）、页脚（联系方式/备案）。
- 组件映射：方向 C 令牌 + Magic UI / Inspira UI 的现成动效（按需复制，别整包）；表单用原生 + 校验。
- 陷阱：Hero 堆三个功能卡却没有主张；「立即开始」出现 5 次；假客户 logo；配图是随机渐变；移动端首屏 CTA 在折叠线以下。
- 验收：3 秒能说出产品干什么；390 宽首屏可见主 CTA；表单错误可读；对比度达标。

## 移动端

```
┌───────────────┐
│ 状态栏/导航    │
│ 内容（单列）   │
│  …            │
│ 主操作（吸底） │
└───────────────┘
```

- 必备：单列信息流、吸底主操作（44px+）、返回路径、触控反馈、弱网骨架屏、下拉刷新（按需）。
- 组件映射：uni-app → Wot Design Uni / uview-plus；Vue3 H5 → Vant。
- 陷阱：固定宽导致横向滚动；只有 hover 才出现的操作；小字号（<14）；弹窗遮住键盘；安全区未适配（`env(safe-area-inset-bottom)`）。
- 验收：390×844 无横向滚动；单手可触达主操作；iOS/Android 键盘弹出不遮输入；列表 200 条滚动流畅。

## 数据大屏

```
┌──────────────────────────────────────────────┐
│ 标题栏（居中大标题 + 时间）                    │
├──────────┬──────────────────┬────────────────┤
│ 左列图表 │ 中央主视图/地图   │ 右列图表/榜单  │
│ (2-3 个) │  + 核心指标       │  + 滚动列表    │
├──────────┴──────────────────┴────────────────┤
│ 底部：滚动播报 / 图例                         │
└──────────────────────────────────────────────┘
```

- 必备：1920×1080 设计稿、缩放适配（v-scale-screen 或 `transform: scale`）、深色底 + 发光配色、数据时间戳、断线占位。
- 组件映射：ECharts（按需）+ CSS/SVG 装饰边框（不依赖已停更的 Vue3 DataV）+ vue3-seamless-scroll。
- 陷阱：只适配 1920，2K/4K 糊；动画过多导致 GPU 掉帧；图表颜色互相打架；没有「数据更新时间」；滚动列表与页面滚动冲突。
- 验收：1366/1920/2560 三档不变形；连续运行 30 分钟内存不涨；断网显示占位而不是空白；远看（3 米）能读出层级。

## 文档站

```
┌──────────┬─────────────────────────┬──────────┐
│ 顶栏：搜索 · 版本 · 主题切换          │
├──────────┼─────────────────────────┼──────────┤
│ 侧目录   │ 正文（标题/代码/表格）   │ 页内目录 │
│ (200)    │ 最大宽 720-760           │ (180)    │
└──────────┴─────────────────────────┴──────────┘
```

- 必备：侧边导航、页内锚点、代码块（复制 + 语言标识）、上一页/下一页、搜索、深浅主题。
- 组件映射：VitePress / Docusaurus 优先；自建则用方向 B 令牌 + Markdown 渲染。
- 陷阱：正文行宽过宽（>90 字符）难读；代码块横向溢出；锚点滚动被固定顶栏遮挡（`scroll-margin-top`）。
- 验收：长文可读性（行宽/行高）；代码块可复制；锚点跳转位置正确；移动端侧栏折叠。

## AI 对话

```
┌────────┬──────────────────────────────────────┐
│ 会话列表│ 消息流（用户右/助手左，流式输出）     │
│ 240    │ 工具调用卡片 / 引用 / 代码块          │
│        ├──────────────────────────────────────┤
│ 新建   │ 输入区：附件 · 提示词 · 发送 · 停止   │
└────────┴──────────────────────────────────────┘
```

- 必备：流式渲染（逐字/逐段）、停止生成、重新生成、复制、代码高亮、长对话虚拟列表、错误重试、空会话引导。
- 组件映射：自研消息流（ChatUI 只作参考）；Markdown 渲染 + 代码高亮（shiki/highlight.js）；输入区用原生 textarea 自适应高度。
- 陷阱：流式时整页重渲染卡顿；消息不自动滚动到底；停止按钮缺失；空状态没有示例问题；代码块溢出。
- 验收：长回答流式不掉帧；滚动跟随但不抢用户手动滚动；停止后状态正确；错误可重试；键盘 Enter 发送、Shift+Enter 换行。
